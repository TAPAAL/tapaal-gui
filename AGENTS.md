# Agent guide

TAPAAL is a Java 17/Kotlin Swing app built with the checked-in Gradle wrapper.

- Testing: read [`.agents/skills/test-tapaal/SKILL.md`](.agents/skills/test-tapaal/SKILL.md) when adding, changing, or running tests and before handing off code changes.
- GUI evidence: read [`.agents/skills/capture-tapaal-gui/SKILL.md`](.agents/skills/capture-tapaal-gui/SKILL.md) when reproducing a UI issue or preparing screenshots/video for an issue or PR.
- Run the app with `./gradlew run`; see the GUI skill for the nested quoting required by model paths containing spaces.
